Système de **rappels d'échéance d'abonnement** livré le 2026-07-05 (**PR #9 MERGÉE dans `main` = `743a18b`**). Prévient AVANT le hard-lock jour-même ([[abonnement-infra-reelle-hardlock]] ADR-0009). Spec+plan dans `docs/superpowers/{specs,plans}/2026-07-05-notifications-echeance-abonnement*`.

**Architecture hybride** (3 audiences, chacune sur son chemin) :
- **admin_groupe** (online) : `pg_cron` quotidien (`0 6 * * *`) pousse des notifs `type='subscription'` dans la cloche à J-30/15/7/1/0, deep-link `data.route='/admin/abonnement'` (le drawer deep-linke DÉJÀ via `data.route` → zéro Dart). Idempotence = table-ledger `subscription_reminder_log` (PK `group_id,subscription_end,threshold`). Réutilise réglages existants `notif_subscription_expiry` (toggle master) + `notif_reminder_days` (seuils CSV).
- **super_admin** (online) : `bucketDunning` (pur) + `dunningProvider` + `DunningPanel` (3 seaux échoit≤7j/grâce/échu-impayé+montant dû) greffé dans `invoices_screen.dart`.
- **personnel école** (offline) : bandeau compte à rebours calculé LOCALEMENT depuis `license.validTo` (déjà signé) — `subscriptionCountdownLabel` pure + `LicenseBanner` étendu. Zéro backend, zéro sync-rule. **Bug latent corrigé** : phase `hardLock` s'affichait en ambre (grâce) → désormais message suspension rouge explicite.

**Invariants** : C4 (jamais de gating synchro), fail-soft partout, notifs ciblent seulement `recipient_id` admin_groupe (aucune fuite staff). 20 tests verts, analyze 0.
