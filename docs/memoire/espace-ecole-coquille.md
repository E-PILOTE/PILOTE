## 🔴🔴 VRAIE CAUSE RACINE de la synchro morte — 2026-06-10 (CRITIQUE)
Après que l'utilisateur ait redéployé SANS effet : preuve par la base locale → seuls les buckets **sans JOIN** descendent (`modules`, `module_categories`, `user_profile`) ; **tous** ceux avec `JOIN profiles` = 0. **PowerSync NE SUPPORTE PAS les `JOIN` dans les `data queries`** (confirmé doc `docs.powersync.com/usage/sync-rules/parameter-queries`).
